A small physics project I made using HTML, CSS and JavaScript.

It shows a simple pendulum that can be controlled using a length slider. The time period is calculated using:

T = 2π√(L/g)

Features
Adjustable pendulum length
Time period calculation
Simple pendulum animation
Pause/Resume button
Built with

HTML 
CSS 
JavaScript

Just open index.html in a browser to run it.

Made this mainly to practice JavaScript and understand the pendulum formula better.
